# وفرلي

تطبيق ميزانية ومحافظ شخصية يعمل على Android وiOS.

## ملاحظة الاختبار
نسخ Android التجريبية من هذا الإصدار وما بعده تستخدم مفتاح توقيع تجريبي ثابت حتى تقبل التحديثات فوق بعضها وتحافظ على البيانات بعد الانتقال الأول. هذا المفتاح للاختبار فقط ولا يُستخدم للنشر التجاري.

## الملفات

- Android Source ZIP
- iOS IPA
- iOS Source ZIP
