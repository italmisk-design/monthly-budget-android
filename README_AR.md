# توفيري

تطبيق لإدارة المحافظ والمصاريف والإيرادات والتحويلات والحركات الشهرية باللغتين IQD وUSD مع واجهة RTL.

من الآن يتم تجهيز نسختين من كل إصدار:
- Android: APK مستقل + Source ZIP مستقل.
- iOS: IPA للتجربة + Source ZIP مستقل.

اللوكو الرسمي: محفظة خضراء مع قطعة نقدية ذهبية واسم «توفيري» داخل الواجهة.

ملف واجهة Android/WebView الرئيسي:
`app/src/main/assets/index.html`

مشروع iOS:
`ios/`
